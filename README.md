# WorkBuddy 智能桌面助理终端 (Model: WB-Terminal-Pro1)

## 1. 产品概述
**WB-Terminal-Pro1** 是一款专为桌面办公场景设计的轻量级 AI 语音与快捷交互硬件终端。通过接入 **WorkBuddy 开放平台**，将大模型的云端任务处理与 PC 本地助理能力延伸至物理桌面，帮助用户在脱离键盘鼠标的间隙快速派发指令并获取状态反馈。

## 2. 硬件规格参数（原型 V1.0）
| 硬件模块 | 规格说明 |
| :--- | :--- |
| **主控芯片** | ESP32-S3 (双核 Xtensa LX7, 240MHz, 支持 Wi-Fi 802.11 b/g/n & BLE 5.0) |
| **显示模块** | 1.54 英寸圆形高清 OLED 状态屏（用于展示账号绑定状态与任务进度） |
| **音频采集** | 双数字硅麦阵列（支持本地VAD语音活动检测与降噪） |
| **交互按键** | 定制机械轴体物理快捷键（支持短按唤醒、长按语音输入） |
| **供电接口** | USB Type-C (5V / 1A) |
| **外壳材质** | CNC 阳极氧化磨砂白铝合金机身 |

## 3. 系统交互架构
1. **设备配网与身份绑定**：用户通过设备热点进入本地配网页面，跳转至 WorkBuddy OAuth 2.0 授权页完成账号绑定。
2. **指令采集与转发**：按下终端物理按键说出指令，固件端完成音频编码后通过安全接口提交至 WorkBuddy 开放平台。
3. **跨端协同执行**：根据指令类型调度云端任务或触发用户 PC 端本地助理执行具体自动化工作流，并在终端 OLED 屏实时回显执行状态。
